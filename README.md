# BODYCRAFT

แอปฟิตเนสส่วนตัวภาษาไทย ใช้งานออฟไลน์ได้ — วางแผนฝึก บันทึกน้ำหนักและน้ำดื่ม แล้วติดตั้งบนหน้าจอโฮม

Offline-first Thai fitness PWA. Plan workouts, log weight and water, and keep using it without a network.

**Live / เปิดแอป:** https://2rit.github.io/BodyCraft/

บน iPhone, iPad หรือ Android ให้เปิดลิงก์ด้านบน แล้วเลือก **Add to Home Screen** (เพิ่มไปที่หน้าจอโฮม) เพื่อติดตั้ง.
